# Rubric: is this a good first issue?

## Checks

| Check | Evidence | Pass condition | Weight |
|---|---|---|---|
| maintainer_alive | Last 5 comments on that issue. | Code maintainer replied to at least 1 of last 5 comments within 30 days of the comment being posted. | required |
| repo_in_use | Last 5 default-branch commit dates. | Should be within past 60 days. | required |
| scope_fits_newcomer | "Labels" section of issue. | "good first issue" label exists. | preferred |
| issue_not_taken | Comment section and assignee field | No one should be assigned this issue. No one else has claimed the issue. No one else has submitted a pull request to solve this issue. | required |
| issue_open | Issue status (just below title). | Issue should be open. | required

## Verdict rule

Accept if every required check passes. Preferred checks do not change the verdict, they just rank accepted issues. Unclear counts as fail.
